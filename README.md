# Simple Todo App

TaskTracker is a lightweight, web-based to-do list application that helps users create, organize, and manage tasks easily.

## Functionality

TaskTracker provides a clean and intuitive interface for managing tasks. On the main page, users can:

- **Add a new to-do**: Enter a description of the task and optionally specify a due date.
- **View task statistics**: See how many tasks are completed vs. total. (To be implemented)
- **Mark tasks as done**: After creating tasks, you can mark them complete (or potentially delete them), which updates the progress count (To be implemented).

## Technologies & Techniques

- **HTML**: For the page structure — form input, headings, task list.
- **CSS**: For the layout and responsive design.
- **JavaScript**: To handle adding tasks, marking them as complete, updating the DOM dynamically, and managing task state.

## Future Enhancements

- Persistence: Use backend database to support storing and retreiving data.

- Task Editing: Allow users to edit existing tasks (change description or due date).

- Reminders: Provide optional reminder notifications (browser notifications or email).

- Task Organization: Introduce categories so tasks can be grouped.

- Allow sorting / filtering by due date, completion status, or category.

- User Accounts: Add authentication so users can log in and sync tasks.

- Implement themes (light / dark mode).
